# 图片预览与二手交易修复验证

日期：2026-10-13。基线：本仓库原 `main`，对照用户提供的 0.1.0-rc.1 APK。

## 变更

- Mojito 优先复用列表 Coil 的磁盘缩略图缓存，避免点开已显示的图片时重复下载缩略图。
- 独立下载使用各自的临时文件，并检查下载长度、图片解码边界；失效缓存不再当作成功结果使用。
- 请求取消和原图加载去重，避免旧请求删除新请求的取消句柄、预览与原图并发覆盖。
- 原图到达后同步预览尺寸，以文件的 EXIF 校正尺寸为准，不再用 URL 中的尺寸覆盖实际图片。
- 去除 Sketch 异步解码前的强制矩阵重置；进场完成后重新识别普通图片时保持 FIT_CENTER，恢复被取消退出暂停的分块渲染。
- Live 图保留静态封面，视频首帧回调后的下一显示帧才开始淡入，不再额外给媒体容器设置黑色背景。
- Live/HDR 图先使用缩略图预览，原图加载遵循图片质量设置；未自动加载原图时，点击“查看原图”后加载富媒体。
- 读取官方 `ershou_info` 字段，支持封面、商品标题、价格、交易来源、交易状态和地区。二手交易商品页使用双列瀑布流，普通动态详情也显示交易信息。
- 支持直接返回的动态和 `verticalColumnsFullPageCard` 内的动态；嵌套商品不会丢失价格与图片字段。
- Protobuf 插件升级至兼容 AGP 9 的 0.10.0，兼容开关写入 gradle.properties。

## 真机验证状态

测试包安装尝试返回 `INSTALL_FAILED_USER_RESTRICTED: Install canceled by user`，正在等待手机允许 USB 安装。因此以下真机回归测试已编译，但尚未执行：

1. Coil 缓存中的已显示缩略图在无网络时可供 Mojito 读取。
2. 同 URL 的两个并发下载各自完成，缓存内容正确。
3. 竖图、横图、EXIF 旋转图、长图拥有有效显示边界，普通图不裁切；保存屏幕截图供复查。
4. 合成 Live 图从静态封面到视频的过渡期间画面中心不黑，且视频实际渲染。
5. 仅有缩略图、关闭自动原图时，“查看原图”按钮仍然可见。

仍需用户提供或在手机打开具体黑屏/显示不全的动态，进行相同图片的修复前后对照；不能把当前状态表述为“所有黑屏图片已真机验证修复”。
