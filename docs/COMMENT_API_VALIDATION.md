# 评论列表读取兼容验证

维护与修复：**tiancaiProgramer**。日期：2026-10-17。

## 原因与对照

- 使用原请求配置（版本名 13.4.1、版本号 2312121、API 13）读取公开动态 `74406267`，`api.coolapk.com` 与 `api2.coolapk.com` 的 `/v6/feed/replyList` 均返回 HTTP 200，业务状态 403，消息“评论接口异常，请尝试升级到新版酷安”。
- 手机原安装版也显示相同消息。切换域名不能解决该错误。
- 酷安官方公开应用详情返回当前版本 16.6.4、版本号 2609291；官方下载 APK 的 MD5 与公开详情元数据一致。该 APK 仅供本地兼容分析，不纳入源码或发布附件。
- 匿名合成请求更新版本后出现验证码要求，不能当作评论读取成功；没有尝试自动完成或绕过验证码。
- 使用手机现有 c001 安装版，在正常设置界面将版本名改为 16.6.4、版本号改为 2609291、API 版本改为 16 后重启，同一动态的评论列表恢复。未复制或导出账号配置、Cookie、个人数字联盟 ID 或设备参数。

## 源码调整

`CommentApiCompat` 仅对官方两个 API 域名、GET 方法和精确路径 `/v6/feed/replyList` 生效，覆盖主评论列表及楼中楼；旧版本读取请求使用上述已验证的配置，并同步 User-Agent 的 CoolMarket 版本后缀。当前和更高版本请求保留原配置。

请求 URL、排序与分页查询、Cookie、X-App-Device、X-App-Token 不变。发送评论的 POST 请求和其他接口不受影响，不修改用户保存的偏好。

## 验证结果与限制

- 设备：小米 15，24129PN74G。
- 现有安装版通过正常设置更新请求配置后：默认列表、最新排序、热门排序及“查看更多回复”的楼中楼页面均显示真实内容，图片与内嵌回复正常。
- 新增 3 项单元测试，验证旧版本读取升级、路径/方法隔离、分页与会话字段保留，以及不降级当前/更高版本配置；应用和媒体模块共 20 项测试通过，0 失败、0 错误。
- 手机参数保留在上述可用的新配置。该手动操作属于全局参数更新，与源码仅处理评论 GET 请求的范围不同；不能用现有安装版参数验证代替新 APK 的覆盖验收。
- 本次没有发布评论、点赞、收藏或发送消息；没有验证全新账号或所有设备。账号/网络要求验证码时仍须按服务端正常流程完成，源码不绕过该要求。
- 本地原发布 keystore 及此前私有 ZIP 已不在原路径，Release 构建因缺少原签名文件而停止。待维护者恢复密钥路径后，再完成原签名覆盖包及其真实旧配置回归。本次未替换 GitHub 已发布 APK 或附件，也未创建新的发布 tag。
