# 应用内官方登录

维护与实现：**tiancaiProgramer**。原登录界面与账号存储来自 bggRGjQaUbCoE 的 c001apk-compose。

## 登录方式

进入“我的”→“点击登录”，直接显示酷安官方手机号登录流程。图片验证由使用者手动完成，短信验证码也由使用者直接在手机上输入；官方页面支持切换账号密码登录。整个流程保留在 c002apk 内，成功后保存账号状态并返回上一页。

右上角“重新加载”会重开登录页；系统返回键优先返回当前官方页面的上一页。配置变化时记住当前官方页面地址，Cookie 由 Android WebView 保留，以便恢复验证步骤。网页中的输入内容不由应用提取或保存，重建页面后可能需要重新输入。

## 本次替换的原因

旧版原生登录界面只处理账号密码及旧图形验证码，未接入官方当前的人机验证脚本和短信验证流程。新版直接使用官方运行中的登录页，保留其验证上下文和请求顺序，不复制验证票据或自行拼装短信发送接口。

- 官方入口：[酷安手机号登录](https://account.coolapk.com/auth/login?type=mobile)。
- 图片验证使用官方页面加载的网易易盾组件，短信发送由使用者点击官方页面按钮发起。
- 已配置的本人数字联盟 ID 只作为酷安域的 DID Cookie 提供；不借用其他人的标识。
- 登录页面只允许 HTTPS 酷安官方域的顶层导航，不自动唤起外部浏览器或第三方应用；手机/密码登录之外的第三方账号跳转暂不支持。
- 成功跳转到官方首页后，使用精确 Cookie 名提取完整 uid、username、token，一次性保存账号及登录标记。凭据不进入日志或发布附件。
- 不清除主应用已有账号数据，不清空 WebView 的全部 Cookie，不注入读取密码或短信验证码的 JavaScript，也不自动完成图形验证。

## 验证

新增导航域、成功跳转、Cookie 精确解析与设备 Cookie 输入校验等单元测试。使用独立 `.logintest` 包检查真实官方页面、验证组件加载、短信/密码页面切换及页面重建；不会向用户手机号发送测试短信或自动完成验证码。完整人工登录的真机结果以发布附件为准。

2026-10-18：应用及媒体模块共 39 项单元测试通过。两轮只读自动真机检查被设备记录为从最近任务清除（SwipeUpClean），未计为通过；没有 Java 应用崩溃堆栈。随后使用者已在独立版应用内的官方登录界面完成人工登录并填写本人数字联盟 ID，客户端“我的”页面显示账号资料，评论及回复入口可见。使用者确认主回复和回复其他评论两个入口均可弹出输入框及键盘。没有退出主应用账号或发送公开测试评论；尚未单独确认短信登录分支与配置重建流程的完整结果。
