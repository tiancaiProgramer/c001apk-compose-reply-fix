# 验证范围

测试日期：2026-10-13（Asia/Shanghai）。

设备：小米 15、HyperOS、Android 16。官方 CoolMarket 13.3.6 正常，按测试者要求未再次发布官方评论。

此前实际请求与单变量实验：

| 版本 / 对照 | 结果 |
|---|---|
| 原版 925abdb，Token 时间为科学计数法 | 业务失败 |
| 仅修复为整数秒、保留原 Device | 业务失败 |
| 整数秒 + 仅替换 Device 第 0 段 + 配套原 v2 Token | 业务成功，唯一新评论读回 |
| 仅改 MAC 段或最后一段 | 失败 |
| 仅删除 replyAndForward=0 | 失败 |
| 将有效首段编译进私有实验 APK，无 Hook | 新评论创建且读回 |

以上对照保留同 Cookie、公共 Header 和 Device 其余字段，定位到源码 szlmId / 数字联盟 ID 设置写入的位置。编译个人标识的私有实验 APK **不作为公开附件**。

本次公开候选 APK 改为运行时配置，验收状态和精确源码/APK 哈希见发布附件 VALIDATION.json。接受一个本人已验证的有效值并不等于自动识别每位用户的 ID，也不能证明所有 36 位文本或所有设备账号都有效。

未测试 float 时间 + 有效首段的独立组合，不声称两项各自均已证明为必要条件。没有伪造官方返回，也没有在公开资料中包含 Cookie、Token、原始设备标识或未脱敏抓包。
